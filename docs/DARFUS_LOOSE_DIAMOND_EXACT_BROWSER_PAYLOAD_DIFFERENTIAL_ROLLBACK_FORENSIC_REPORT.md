## 18. Root Cause Evidence

The evidence chain is:

1. Backend Loose Diamond preview returns current tax data under `current.taxSnapshot`.
2. The frontend prepared-request builder reads `preview.current?.currentTax?.effectiveVatRate`.
3. `preview.current.currentTax` is not the returned property, so the prepared `currentValuation.vatRate` property is undefined and disappears during JSON serialization.
4. `normalizeReceiptPiece` preserves the supplied `currentValuation` object.
5. `persistReceiptEvidence` builds the `asset_current_valuations` INSERT with `vatRate: currentValuation.vatRate`.
6. Sequelize rejects the undefined named replacement before the INSERT executes.
7. Adding only the missing nested field with value `14` removes the exception and lets the full route reach the commit barrier.

Relevant source evidence:

- Frontend mapping: `app/[locale]/(dashboard)/inventory/loose-diamond/page.tsx:123`.
- Backend preview response: `backend/src/services/loose-diamond-profile.service.js:194-200`, where current tax is returned as `taxSnapshot`.
- V2 normalization preservation: `backend/src/services/inventory-v2-runtime.service.js:226-277`.
- Failing persistence INSERT: `backend/src/services/inventory-v2-runtime.service.js:427-437`.
