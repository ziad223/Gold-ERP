## 2. Root cause

The previous C2C3 blocker treated a toolchain-generated import transition as a protected source drift. Next.js 16.2.9 can generate:

- dev: `./.next/dev/types/routes.d.ts`
- build: `./.next/types/routes.d.ts`

The safe correction is policy classification, not editing the generated file. The policy requires the complete standard template and exact supported path; it does not accept arbitrary generated paths or manually edited content.
