Host source `backend/src/routes/erp.routes.js` (last write `2026-08-27 10:07:23Z`) contains the active issue route, بينما الـcontainer process بدأ `2026-08-27 08:43:11Z` وخدم guard قديمًا يعيد `GIFT_VOUCHER_FINANCIAL_WORKFLOW_DISABLED`. كما ظهرت read-side `GET /api/v1/gift-vouchers` 500 من runtime الحالي؛ لا يوجد دليل على DB corruption.
