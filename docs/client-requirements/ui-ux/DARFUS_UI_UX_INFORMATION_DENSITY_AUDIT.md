# Information Density Audit

The system has 68 page files and many domain fields. Dashboard is visually balanced but vertically long due the gold-price panel. Inventory profile forms expose 5–9 numbered sections and many inputs; this is operationally rich but risks equal visual weight. Inventory list is a dense table with filters and one row per Asset; accounting chart/audit/approvals can be especially dense.

Findings: P1 for critical profile forms where required/core/advanced fields are not visually differentiated; P2 for long sidebar, repeated cards, and long vertical reads. Future patterns: grouped field priority, sticky filter/header bars, column visibility, progressive disclosure, and side drawers. No business field or workflow change is proposed here.
