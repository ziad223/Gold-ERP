# UX-7 Scope Classification

| Surface | Class | Decision |
|---|---|---|
| Customer list | A/B | Presentation hierarchy, table readability, scoped responsive treatment |
| Customer detail | B/C | Presentation hooks only; workflow-sensitive controls retained |
| Customer create/edit modal | C | Form grid/readability only; submit and validation unchanged |
| Supplier list | A/B | Card/list readability, identifiers and action hierarchy |
| Supplier detail | B/C | Presentation hooks only; payment/document/consignment actions retained |
| Supplier create/edit modal | C | Form grid/readability only; payload and handlers unchanged |
| Loyalty, supplier purchases and unrelated modules | D | Deferred; no source change |
