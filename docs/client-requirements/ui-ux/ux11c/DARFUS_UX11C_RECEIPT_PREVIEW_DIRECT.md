# ReceiptPreview Direct Proof

The disposable route mounted the actual `ReceiptPreview` component with the existing `Invoice` contract and synthetic non-persistent invoice values. AR and EN both showed header, line items, totals, payment, document frame, and no clipping. At 840x1180 the frame was visible and body/document widths equaled the viewport. Light and Dark shell checks preserved the fixed white document frame.

`RECEIPT_PREVIEW_DIRECT = PASS`; `RECEIPT_PREVIEW_TABLET = PASS`.
