# Preview Theme Isolation

Source and reachable browser evidence agree that UX11 scopes the preview surface and fixed machine-readable/tag faces. The Asset tag remained white/dark-readable across shell themes. `BARCODE_PAYLOAD_CHANGED = NO`, `QR_PAYLOAD_CHANGED = NO`, and `MACHINE_READABLE_IDENTITY_CHANGED = NO`. Full four-component browser isolation is not claimed because two components have no current mount.
