# UX-2 Classic Screenshot Baseline

The classic visual baseline is retained before UX-2 foundation work. Existing accepted pre-UX2 captures are reused as historical visual evidence where available; no business data was created to obtain them.

| Surface | Locale/theme evidence | Viewport/evidence |
|---|---|---|
| Dashboard | Existing UX-0/UX-0B capture set | Desktop and narrow captures in prior UX reports |
| POS | Existing POS visual baseline | `backend/reports/pos-phase-01-1280x800.png`, `pos-phase-01-1440x900.png`, `pos-phase-01-tablet-768x800.png` |
| Inventory / Asset | Existing UX-0 route baseline | UX-0/UX-0B screenshot baseline artifacts |
| Customers / Suppliers | Existing route baseline | UX-0/UX-0B report artifacts |
| Gold Center / Accounting / Treasury / Settings / Tax | Existing route baseline | UX-0/UX-0B report artifacts |
| Tag / Print | Existing print/tag captures | `backend/reports/` print/tag evidence |

The prior baseline is a documented partial cross-product capture, not a claim that every route had every state. UX-2 after-proof uses representative routes and compares readability, controls and contrast only.
