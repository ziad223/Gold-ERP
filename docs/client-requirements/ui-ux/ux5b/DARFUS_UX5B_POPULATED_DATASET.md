# UX5B Populated Dataset

Four display-only rows were used to exercise density: GBW ring, Diamond bracelet, Pearl necklace, and Gemstone earrings. Each row includes a long description, profile, barcode, karat, decimal weight, price, total, and remove affordance. Customer, address, phone, notes, monetary totals, selected Cash, disabled Installment/Deposit, and Gift Voucher presentation were also represented.

All values are display fixtures only. They are not pricing, VAT, payment, inventory, Asset, barcode, or accounting authority. No fixture row was inserted into any database.
