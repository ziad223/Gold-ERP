# Accessibility Pattern Research

Future UX-1 rules: every control has a visible or programmatic label; icon-only actions have names; focus is visible and keyboard reachable; errors are adjacent and announced; disabled/read-only states remain distinguishable; contrast is measured; touch targets are usable; dialogs manage focus; tables expose headers; tooltips work by focus and touch; motion respects `prefers-reduced-motion`. This is not a WCAG certification and no source was changed.
