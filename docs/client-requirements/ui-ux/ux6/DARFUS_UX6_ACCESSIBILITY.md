# UX-6 Accessibility

- Search has an explicit screen-reader label: `Search inventory assets` / `البحث في الأصول`.
- Table has a screen-reader caption and column scopes.
- Visible status text accompanies status tone; color is not the sole signal.
- Existing shared Button/input focus-visible and keyboard behavior was preserved.
- Existing links/buttons and the table's touch-scroll surface remain usable on touch devices.
- No modal, drawer, or focus restoration contract was changed; UX4C remains closed.
