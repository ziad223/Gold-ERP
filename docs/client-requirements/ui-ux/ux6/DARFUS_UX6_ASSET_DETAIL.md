# UX-6 Asset Detail

The detail page keeps the existing Asset, source, branch/location, cost, valuation, barcode, RFID, movement, history, revision, return-review, and permission authorities. UX-6 only improved the `Field` typography, wrapping, spacing, numeric readability, and localized operational-status presentation via the existing `lifecycleState` helper.

Existing mutation handlers remain present and unchanged: return review, restock approval, metadata revision, selling-price revision, and RFID actions. No new action or endpoint was added.
