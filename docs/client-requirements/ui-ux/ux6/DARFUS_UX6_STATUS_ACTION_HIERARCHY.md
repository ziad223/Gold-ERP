# UX-6 Status / Action Hierarchy

- Status remains derived from server `operationalStatus` and uses the existing Badge tone mapping.
- English status filter/list labels are readable (`Available`, `Reserved`, `Sold`, `Pending transfer`, `In workshop`, `Returned`, `Missing`, `Melted`) instead of raw enum codes.
- Arabic status labels remain localized through the existing map.
- Status is not color-only: text remains visible.
- Detail actions, visibility gates, permission checks, and lifecycle transitions are unchanged.
