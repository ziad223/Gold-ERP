# UX-11 Scope Classification

| Change area | Classification | Decision |
|---|---|---|
| Preview surfaces | A — presentation-only | In scope |
| Fixed-format print CSS | A — presentation-only | In scope; no document contract changes |
| Barcode/QR visual frame | A/E — presentation and machine-readable display | In scope; payload immutable |
| Server print/reprint authorization | C/D — business/security authority | Frozen; no changes |
| Invoice/receipt values | C — business document contract | Frozen; no changes |
| Gift Voucher state/accounting | C — business state | Frozen; open prevention item preserved |
| CGP repeated-print recovery | C/D — business/recovery authority | Frozen; open item preserved |
| API/routes/DB/migrations | C | Out of scope |
