# UX-11 Print Media CSS

The shared `lib/print/print-config.ts` continues to provide `@page`, print-root white background, fixed paper sizes, page-break rules, screen chrome hiding, barcode direction, and print color adjustment. UX-11 adds only `color-scheme: light` and `forced-color-adjust: none` to print HTML/root/barcode visual rules. No template fields, values, totals, or document identifiers were changed.
