# UX-11 Barcode / QR Sweep

`ScannableBarcode` remains the renderer and still receives the existing stored value. Barcode label and Asset tag previews keep their existing permission guards and `printHtmlDocument` handlers. No barcode, QR, RFID, Asset ID, encoding, format, or value source changed. The UX11 change only isolates the visual frame and preserves LTR machine-readable content.
