# Modern Enterprise Pattern Research

The most applicable evidence is SAP Fiori's separation of responsive tables from desktop-centric analytical tables and Microsoft Fluent's explicit breakpoint/size-class approach. Carbon reinforces configurable tables with consistent actions and accessibility expectations. DARFUS should adopt task-based responsive projections, primary identity preservation, priority columns, contextual details, and clear action hierarchy.

Future candidates: sticky summary/action areas where they do not cover content, progressive disclosure for advanced fields, filter bars with saved views, compact/comfortable modes, and list/detail on small screens. `MORE_DATA != MORE_CARDS`. No table behavior or workflow was changed in UX-0B.
