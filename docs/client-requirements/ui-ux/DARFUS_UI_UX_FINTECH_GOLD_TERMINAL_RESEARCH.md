# Fintech / Gold Terminal Research

Bloomberg's public product reference emphasizes real-time data, research, analytics, configurable workspaces, and fast decisions. TradingView's Lightweight Charts reference emphasizes high-performance chart/data rendering and streaming updates. DARFUS adaptation: tabular numerals, explicit units, strong base/VAT/total hierarchy, aligned debit/credit/balance columns, visible freshness/source for market data, compact filters, and low-latency confirmation feedback.

Charts are not proposed by default. Terminal mimicry, unexplained ticker-like density, dark-only presentation, and keyboard conventions that are not already part of DARFUS are rejected. Financial presentation remains separate from calculation, tax, and accounting authorities.
