# UX-1R Inventory / Asset Production Refinement

The Inventory / Asset reference retains the approved identity and presents Asset, Barcode, Status, Branch, Location, Supplier, Gross Weight, Net Weight, Karat, Making / g, Current Cost, Sale Price and Gold Rate in a compact field grid and summary strip.

It remains a read-only fixture and does not alter inventory authority, Asset identity or barcode behavior.
