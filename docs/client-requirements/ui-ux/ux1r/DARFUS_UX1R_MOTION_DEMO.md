# UX-1R Motion Demonstration

Visible, restrained demonstrations are present in the isolated prototype:

- prototype/tab transition (`prototypeEnter`);
- active tab color/border transition;
- input focus outline transition;
- item-row/status surface transition;
- motion-demo feedback rail.

Motion uses short opacity/transform or state transitions. It does not delay checkout, move financial values, loop infinitely, or alter business state.
