# UX4B Accessibility Evidence

- Required interactive families expose semantic roles for buttons, textboxes/searchboxes, combobox/listbox/options, checkbox/radio/switch, tabs, table headers, alerts, status, dialogs, and navigation where applicable.
- Icon-only and close controls were named and discoverable by role/label.
- Disabled and read-only states were represented by native/ARIA-compatible state signals.
- Error/helper text was visible adjacent to the relevant reference control.
- Keyboard tooltip activation worked.
- Modal focus entry and return passed.
- Drawer focus entry passed, but Drawer focus return failed (`BODY` after close).

`ACCESSIBILITY_EVIDENCE = PARTIAL`; this is not a claim that all UX4 accessibility requirements pass.
