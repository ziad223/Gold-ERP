# DARFUS-PREVIEW-THEME-ISOLATION-GATE-001

Permanent prevention rule created by UX-6B.

Every future Barcode, QR, Tag, Label, Print Preview, Receipt Preview, Document Preview, machine-readable surface, or fixed-format output must prove:

```text
Light = PROVEN
Dark = PROVEN
AR = PROVEN
EN = PROVEN
Desktop = PROVEN
Mobile/Tablet as applicable = PROVEN
Print/preview contrast = PROVEN
Theme inheritance boundary = PROVEN
Business/encoded value unchanged = PROVEN
```

If output is intended for white paper, the innermost printable surface must explicitly isolate a print-safe background and foreground. No stage may close on a parent-page screenshot alone. A changed/high-risk embedded component requires direct same-state Light/Dark evidence.

From UX-6B onward: `THEME_PARITY_SWEEP = PASS` is required before closing each UI/UX stage.
