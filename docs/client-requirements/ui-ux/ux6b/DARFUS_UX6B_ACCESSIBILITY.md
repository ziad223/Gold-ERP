# UX-6B Accessibility

The existing permission-gated `Print tag` / `طباعة التاج` button remains keyboard reachable with the shared Button focus behavior. The tag's barcode and human-readable code remain visible as text; contrast is no longer theme-dependent. RTL changes layout direction of the tag faces but not barcode direction or encoded value. The existing local overflow surface supports touch viewing on small screens.

No new control, label, or interaction path was introduced.
