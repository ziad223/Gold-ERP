# UX-1 Typography System

Arabic UI uses a readable Arabic face with sufficient x-height, line-height and weight for dense labels and tables. English UI uses a crisp operational sans. Headings and section titles create hierarchy; labels/helpers remain compact but readable; tables and codes use stable widths and tabular numerals where numeric comparison matters.

Weights, gold weights, document references and codes must preserve their domain meaning. Numeric islands use LTR direction in RTL screens. Stored business data is not translated or reformatted by this visual specification. No business wording was changed.
