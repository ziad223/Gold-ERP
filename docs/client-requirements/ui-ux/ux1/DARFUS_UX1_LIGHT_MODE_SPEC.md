# UX-1 Light Mode Specification

Light mode is an authored system, not a dark inversion: warm ivory canvas, crisp white surfaces, graphite text, controlled warm borders, minimal gold emphasis and clear financial comparison. Default, hover, focus, active, selected, disabled, readonly, error, warning, success and loading states require their own contrast review.

Do not allow pale blocks, weak borders, low-contrast disabled text or gold-on-ivory failures. Financial numerics remain crisp and aligned. This is a future specification and does not change current production CSS.
