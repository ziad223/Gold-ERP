# UX-1 Table / Data Grid System

Use sticky headers where safe, primary identity first, priority columns, column visibility, compact/comfortable modes, safe frozen columns, filtering, sorting, action menus, responsive row detail/list-detail adaptation, totals/footer, empty/loading/error states and keyboard clarity. Use horizontal scroll only when it is intentional and communicated.

Accounting, Treasury and Gold Center use tabular numerals, stable column widths, aligned Debit/Credit/Balance and minimal motion. Do not convert every table to cards; choose the task-appropriate representation.
