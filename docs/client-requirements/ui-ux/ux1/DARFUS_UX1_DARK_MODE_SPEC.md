# UX-1 Dark Mode Specification

Foundation: layered obsidian/graphite surfaces, warm readable foregrounds, precise borders and restrained gold. States are independently specified: default, hover, focus, active, selected, disabled, readonly, error, warning, success and loading.

Gold is never used for every button, border, icon or card. No casino black/gold, constant glow, metallic gradients everywhere, or luxury imagery in operational screens. Financial values do not animate during normal reading. Focus must remain visible against every dark surface. Disabled and readonly must remain distinguishable without relying on color alone.

Acceptance is a future UX-1 implementation gate, not a claim about all production routes in this control.
