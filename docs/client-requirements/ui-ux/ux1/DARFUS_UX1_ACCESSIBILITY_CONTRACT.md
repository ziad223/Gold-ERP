# UX-1 Accessibility Contract

Baseline: accessible name, visible/programmatic label, visible focus, keyboard access, adequate touch target, meaningful disabled/readonly state, clear adjacent error, semantic headings/table headers, dialog focus management, tooltip focus/touch support, and reduced-motion support. Icon-only controls require an accessible name and a tooltip where useful.

This is a practical baseline, not a WCAG certification. Business data language is exempt from UI chrome purity, but raw backend messages are not user-facing translations.
