# Prototype B — Inventory / Asset

Static reference only. The isolated surface represents Asset identity, Barcode, Status, Gross/Net weight, Karat, Making, Location, Supplier and current/sale cost presentation. It treats Asset/barcode as identity display and does not create, edit, move or value an item.

Visual response: identity hero, grouped detail fields, concise status and summary strip. Functional behavior unchanged: no inventory mutation, no Product quantity authority, no backend call.
