# UX-1 Form System

Use a visual hierarchy of Core Information, Product/Asset Identity, Gold/Material, Pricing, Financial, Operational, Optional and Advanced. Required/optional and inline validation must be obvious. Use progressive disclosure, collapsible advanced sections, contextual help and safe sticky summaries when they do not obscure content.

Do not remove or rename business fields, infer defaults, change requiredness, or convert an existing workflow to a wizard unless equivalent business stages already exist. A visual prototype is read-only and cannot define a new field or workflow.
