# UX-1 Responsive System

| Class | Reference width |
|---|---:|
| Wide Desktop | 1440+ |
| Desktop | 1280 |
| Laptop | 1024–1199 |
| Tablet Landscape | 900–1024 |
| Tablet Portrait | 768–899 |
| Mobile Large | 430–767 |
| Mobile Small | 360–429 |

Adapt by content priority, not only shrinkage. Keep primary identity/action visible; move lower-priority content to row details, drawers or expandable sections; keep POS search/customer/payment/total reachable; use list/detail for mobile when tables are too complex. Sticky bars must not cover content. Validate every class in real browser. No workflow or API change is implied.
