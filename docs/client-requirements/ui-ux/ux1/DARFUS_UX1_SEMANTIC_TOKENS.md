# UX-1 Semantic Tokens

| Category | Dark intent | Light intent |
|---|---|---|
| canvas | obsidian/navy foundation | warm ivory/premium neutral |
| surface-1 | primary work surface | crisp white work surface |
| surface-2 | nested graphite surface | warm neutral nested surface |
| surface-3 | stronger grouping surface | slightly darker warm grouping |
| surface-elevated | overlay/elevated surface | elevated white |
| surface-interactive | hover/interactive layer | warm interactive layer |
| surface-selected | restrained gold wash | restrained warm-gold wash |
| text-primary/secondary/muted/inverse | high contrast hierarchy | graphite hierarchy |
| text-gold | reserved priority value | reserved priority value |
| border-subtle/default/strong | calibrated cool borders | calibrated warm/graphite borders |
| gold-primary/muted/highlight/contrast | warm metallic accent | controlled warm accent |
| success/warning/danger/info | semantic status colors | independently measured semantic colors |
| focus/disabled/overlay/shadow | visible focus, subdued disabled | visible focus, subdued disabled |

Recommended scales are semantic, not raw hex contracts. `radius`, `spacing`, `type-scale`, `z-index`, `breakpoints`, `motion-duration`, and `motion-easing` are defined by the companion contracts. This is specification only; production tokens were not changed.
