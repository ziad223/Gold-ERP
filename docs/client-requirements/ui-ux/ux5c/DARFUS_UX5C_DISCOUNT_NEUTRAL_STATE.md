# UX5C — Discount Zero Neutral State

The discount input still binds to the same `discount` state and the same
`onChange` normalization. Its visual text class is neutral when the numeric value
is zero and retains the existing danger accent only when a positive discount is
shown in the financial breakdown.

`DISCOUNT_ZERO_VISUAL_STATE = NEUTRAL`
`DISCOUNT_BEHAVIOR_CHANGED = NO`
