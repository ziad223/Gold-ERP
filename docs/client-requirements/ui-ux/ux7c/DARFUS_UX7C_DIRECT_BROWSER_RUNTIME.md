# UX7C Direct Browser Runtime

The direct runtime used local Playwright with the verified Chrome executable in a headless ephemeral browser context. Owner personal Chrome profile was not touched.

```text
BROWSER_ENGINE = Chromium via local Chrome
BROWSER_EXECUTABLE = C:\Program Files\Google\Chrome\Application\chrome.exe
BROWSER_VERSION = 151.0.7922.174
AUTOMATION_METHOD = PLAYWRIGHT_CHROME
PLAYWRIGHT_VERSION = 1.51.1
TEMP_PROFILE = Playwright ephemeral browser context
DIRECT_BROWSER_RUNTIME_PROVEN = YES
PERSONAL_BROWSER_PROFILE_TOUCHED = NO
```

The browser was closed after the attempt. No temporary browser process remained.
